## 確認

02.mdで、設定した内容 BP loot_tables/blocks/loot_surface_block.jsonの中身はこうなっている。

```

{
  "pools": [
    {
      "rolls": 1,
      "entries": [
        {
          "type": "item",
          "name": "akd_loot_block:loot_surface_block"
        }
      ]
    }
  ]
}

## 変更

```

これを、こうする。

```

{
  "pools": [
    {
      "rolls": {
        "min": 1,
        "max": 2
      },
      "entries": [
        {
          "type": "item",
          "name": "minecraft:iron_ingot", # 鉄インゴット
          "weight": 1
        },
        {
          "type": "item",
          "name": "minecraft:white_wool", # 白いウール
          "weight": 2,
          "functions": [
            {
              "function": "set_count",
              "count": 3
            }
          ]
        },
        {
          "type": "item",
          "name": "minecraft:wheat_seeds",
          "weight": 3,
          "functions": [
            {
              "function": "set_count",
              "count": 8
            }
          ]
        },
        {
          "type": "item",
          "name": "minecraft:oak_log",

          "functions": [

            }
```
