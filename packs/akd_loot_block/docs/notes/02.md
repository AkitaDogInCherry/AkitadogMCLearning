# 宝物ブロックアドオン - ブロックのプロトタイプを作成

[1つ上へ](./index.md)

## `loot_surface_block` に関係するフォルダ構成

現在の `loot_surface_block` は、ビヘイビアーパック（ブロックの挙動・ドロップ）とリソースパック（テクスチャ・サウンド）を組み合わせて実現している。

```text
.
├─ akd_loot_block_bp/                         # ビヘイビアーパック
│  ├─ manifest.json                           # BPをMinecraftに認識させる
│  ├─ blocks/
│  │  └─ loot_surface_block.json              # ブロック本体の定義
│  └─ loot_tables/
│     └─ blocks/
│        └─ loot_surface_block.json            # 破壊時のドロップを指定
└─ akd_loot_block_rp/                         # リソースパック
   ├─ manifest.json                           # RPをMinecraftに認識させる
   ├─ blocks.json                             # ブロックのサウンドを指定
   └─ textures/
      ├─ terrain_texture.json                 # テクスチャ名と画像を対応付ける
      └─ blocks/
         └─ loot_surface_block.png            # ブロックに表示する画像
```

## 各ファイルの役割

### `akd_loot_block_bp/manifest.json`

ビヘイビアーパックの名前、UUID、バージョンなどを定義する。Minecraftがこのフォルダをビヘイビアーパックとして読み込むために必要になる。

### `akd_loot_block_bp/blocks/loot_surface_block.json`

識別子 `akd_loot_block:loot_surface_block` を持つカスタムブロック本体を定義する。

主に次の内容を設定している。

- フルブロックの形状
- `loot_surface_block` というテクスチャ名
- 当たり判定と選択範囲
- 採掘時間と爆発耐性
- 破壊時に参照するルートテーブル

このファイルの `minecraft:material_instances` にあるテクスチャ名が、リソースパックの `terrain_texture.json` を参照する。

### `akd_loot_block_bp/loot_tables/blocks/loot_surface_block.json`

ブロックを破壊したときのドロップを定義する。現在は `loot_surface_block` 自身を1個ドロップする。

### `akd_loot_block_rp/manifest.json`

リソースパックの名前、UUID、バージョンなどを定義する。Minecraftがテクスチャとサウンド設定を読み込むために必要になる。

### `akd_loot_block_rp/blocks.json`

識別子 `akd_loot_block:loot_surface_block` のブロックサウンドを定義する。現在は `sound` に `gravel` を指定している。

サウンドはBPの `minecraft:material_instances` には記述せず、RP直下のこのファイルに記述する。

### `akd_loot_block_rp/textures/terrain_texture.json`

BPのブロック定義で使っているテクスチャ名 `loot_surface_block` と、画像パス `textures/blocks/loot_surface_block` を対応付ける。画像パスでは拡張子 `.png` を省略する。

### `akd_loot_block_rp/textures/blocks/loot_surface_block.png`

ブロックの各面に表示する16×16ピクセルの画像ファイル。

## 主な参照の流れ

blocks.json以外は

```text
BP blocks/loot_surface_block.json
    ├─ BP loot_tables/blocks/loot_surface_block.json
    ├─ RP blocks.json
    └─ RP textures/terrain_texture.json
        └─ RP textures/blocks/loot_surface_block.png
```

ブロック本体は、破壊時にはルートテーブルを、描画時にはテクスチャ定義とPNG画像を参照する。同じブロック識別子に対するサウンドは、RP直下の `blocks.json` で設定する。

なお、ブロックの `minecraft:geometry` と `minecraft:material_instances` はBP側のブロック定義に置く。`minecraft:material_instances` の中では、テクスチャ名や描画方法を設定し、`sound` は設定しない。

## 各ファイルの中身

### BP blocks/loot_surface_block.json

```json
{
  "format_version": "1.26.40",
  "minecraft:block": {
    "description": {
      "identifier": "akd_loot_block:loot_surface_block"
    },
    "components": {
      "minecraft:geometry": "minecraft:geometry.full_block",
      "minecraft:material_instances": {
        "*": {
          "texture": "loot_surface_block",
          "render_method": "opaque"
        }
      },
      "minecraft:collision_box": true,
      "minecraft:selection_box": true,
      "minecraft:destructible_by_mining": {
        "seconds_to_destroy": 0.5
      },
      "minecraft:destructible_by_explosion": {
        "explosion_resistance": 0.5
      },
      "minecraft:loot": "loot_tables/blocks/loot_surface_block.json"
    }
  }
}
```

### BP loot_tables/blocks/loot_surface_block.json

```json
{
  "pools": [
    {
      "rolls": 1,
      "entries": [
        {
          "type": "item",
          "name": "akd_loot_block:loot_surface_block"
        }
      ]
    }
  ]
}

```

### RP blocks.json

```json
{
  "format_version": "1.19.30",
  "akd_loot_block:loot_surface_block": {
    "sound": "gravel"
  }
}
```

### RP textures/terrain_texture.json

```json
{
  "texture_name": "atlas.terrain",
  "resource_pack_name": "akd_loot_block_rp",
  "texture_data": {
    "loot_surface_block": { "textures": "textures/blocks/loot_surface_block" }
  }
}
```
