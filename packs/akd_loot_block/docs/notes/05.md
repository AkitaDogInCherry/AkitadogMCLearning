# 宝物ブロックアドオン - feature_rulesとfeaturesを改めて理解する

[1つ上へ](./index.md)

## 理解する

解釈順は、

```

feature_rule -> feature

```

の順である。

以下はfeature_ruleとfeatureの例。

### loot_surface_common_rule.json

```json:loot_surface_common_rule.json

{
  "format_version": "1.26.40",
  "minecraft:feature_rules": {
    "description": {
      "identifier": "akd_loot_block:loot_surface_common_rule",
      "places_feature": "akd_loot_block:loot_surface_common"
    },

    "conditions": {
      "placement_pass": "after_surface_pass",

      "minecraft:biome_filter": [
        {
          "test": "has_biome_tag",
          "operator": "==",
          "value": "overworld"
        }
      ]
    },

    "distribution": {
      "iterations": 2,

      "scatter_chance": {
        "numerator": 1,
        "denominator": 16
      },

      "coordinate_eval_order": "xzy",

      "x": {
        "distribution": "uniform",
        "extent": [0, 15]
      },

      "z": {
        "distribution": "uniform",
        "extent": [0, 15]
      },

      "y": "query.heightmap(variable.worldx, variable.worldz) - 1"
    }
  }
}

```

### loot_surface_common.json

```json:loot_surface_common.json

{
  "format_version": "1.26.40",
  "minecraft:single_block_feature": {
    "description": {
      "identifier": "akd_loot_block:loot_surface_common"
    },
    "places_block": "akd_loot_block:loot_common",
    "may_replace": [

      "minecraft:dirt"
    ],
    "enforce_placement_rules": false,
    "enforce_survivability_rules": false
  }
}

```

### feature_ruleとfeature

ruleの方は、「どういう条件の時に、どこに生成の種を置くか」のような意味合いである。

一方、featureの方は、「置かれた生成の種に対してどのようにモノを置くか」を決める。

ここで、

> "minecraft:single_block_feature"

と書かれているのが重要な部分であり、これは「種の位置に1つのブロックを置く」という最も単純なfeatureである。

どのブロックを置換するか、といったことは書かれているが、位置に関しては「種の位置そのまま」なので、特に情報は書かれていない。

これに対し、

> "minecraft:scatter_feature"

というものがあり、これは「種の位置に対し、散らばらせる」という意味を持つfeatureである。

注意点として、scatter_feature自体はブロックを配置しない。scatter_feature内で

> "places_feature": "(別のsingle_block_featureなどのfeature)"

と指定することで、種をばらけさせた後で、その位置に配置することができる。

featureには

| 配置方法             | 主に使うFeature                                        | 例えば                  |
| ---------------- | -------------------------------------------------- | -------------------- |
| 地表に1個            | `single_block_feature`                             | 今作っている方式             |
| 地表に数個まとまって出現     | `scatter_feature` → `single_block_feature`         | かぼちゃ・花畑風             |
| 地下に鉱脈状           | `ore_feature`                                      | 鉄鉱石・石炭鉱石風            |
| 洞窟の壁に埋め込む        | `snap_to_surface_feature` → `single_block_feature` | 洞窟壁ラッキーブロック          |
| 洞窟の床に置く          | `snap_to_surface_feature`                          | 宝箱・キノコ風              |
| 洞窟の天井に置く         | `snap_to_surface_feature`                          | 吊り下がったブロック           |
| 壁・床・天井に広がる       | `multiface_feature`                                | グロウライケン風             |
| 丸い塊として埋まる        | `partially_exposed_blob_feature`                   | 岩塊・巨大鉱石風             |
| パッチ状に広がる         | `vegetation_patch_feature`                         | 苔・キノコ・カボチャ畑風         |
| A/B/Cからランダム選択    | `weighted_random_feature`                          | Common/Rare/Epicブロック |
| 複数Featureをまとめて発生 | `aggregate_feature`                                | ラッキーブロック＋周囲に金鉱石      |
| 決まった順序で生成        | `sequence_feature`                                 | 地面を作る→その上にブロック       |
| 周囲から置ける場所を探す     | `search_feature`                                   | 木の葉の中、壁際など           |
| 任意の建造物を生成        | `structure_template_feature`                       | 小さな祭壇＋ラッキーブロック       |
| 晶洞のような構造         | `geode_feature`                                    | ラッキー晶洞               |
| 水底に半分露出した塊       | `partially_exposed_blob_feature`                   | 海底宝石塊                |

と、様々な配置方法を実現する多数のfeatureがある。

feature_ruleで種を作る→その種の位置を基準としてfeatureを連鎖させていくことにより、複雑な配置の生成を行う。
