# 宝物ブロックアドオン - ブロックの性質を設定

[1つ上へ](./index.md)

## 概要

ここでは以下の性質を設定する。

- 明るさ3で光らせる
- 自身は光は透過させない
- 持った時のアイテム名を「お宝ブロック」にする

## 明るさ3で光らせる・自身は光を透過させない・名前を「お宝ブロック」にする

すべてloot_surface_block.jsonを以下のように編集することで実現できる。

なお、多言語対応する場合は言語ファイル的なものを作る必要がある。

```json

{
  "format_version": "1.26.40",
  "minecraft:block": {
    "description": {
      "identifier": "akd_loot_block:loot_surface_block"
    },
    "components": {
      "minecraft:display_name": "お宝ブロック", # 追加
      "minecraft:geometry": "minecraft:geometry.full_block",
      "minecraft:material_instances": {
        "*": {
          "texture": "loot_surface_block",
          "render_method": "opaque"
        }
      },
      "minecraft:collision_box": true,
      "minecraft:selection_box": true,
      "minecraft:light_dampening": 15, # 追加
      "minecraft:light_emission": 3, # 追加
      "minecraft:destructible_by_mining": {
        "seconds_to_destroy": 0.5
      },
      "minecraft:destructible_by_explosion": {
        "explosion_resistance": 0.5
      },
      "minecraft:loot": "loot_tables/blocks/loot_surface_block.json"
    }
  }
}

```
